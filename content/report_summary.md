## 포지셔닝

Problem Solver, Denny는 초기 창업자의 MVP 개발 외주 문제를 해결하는 기술 파트너다. 핵심 고객은 비싼 외주 견적, 낮은 품질, 소통 부재, 기술 의사결정 부담을 겪는 초기 창업자다.

## 핵심 메시지

초기 창업자에게 필요한 것은 단순한 개발자가 아니라 문제 정의, 우선순위, 검증 방법까지 함께 잡아주는 파트너다. LLM 시대에는 구현 자체보다 무엇을 만들지, 어떤 가설을 먼저 검증할지, 비용을 어디까지 줄일지가 더 중요하다.

## 실제 사례

- 고객 A: 3,000만 원을 들인 홈페이지가 제대로 작동하지 않았고 개발사와 연락도 어려웠다. Denny는 100만 원에 새 홈페이지를 제작해 비용을 약 96.7% 줄였다.
- 고객 B: MVP 개발에 4,000만 원 견적을 받았다. Denny는 무료 컨설팅으로 MVP의 본질과 가설 검증 방법을 설명하고 간단한 MVP를 제공했다. 이후 고객은 투자 유치까지 성공했다.

## 경험과 신뢰 자산

- 4년 8개월 개발 경력
- 음성 대화형 AI 서비스 개발 총괄
- B2B SaaS 플랫폼 개발
- ChatGPT 기반 AI 서비스 개발
- TIPS R&D 선정 경험
- 초기 고객 30명을 확보했지만 시드 투자 유치에 실패하며, 기술만으로는 성공할 수 없다는 교훈을 얻음

## 콘텐츠 원칙

- 실제 경험과 숫자를 기반으로 쓴다.
- 초기 창업자의 불안을 먼저 이해하고, 바로 실행 가능한 판단 기준을 제시한다.
- 과장된 성공담보다 실패와 시행착오에서 얻은 기준을 공유한다.
- 주제는 MVP, 외주 개발, LLM 활용, 기술 의사결정, 창업 경험담에 집중한다.
